How to manage individual annotation objects?

Current annotate app: Classes with count badges but no per-object list. Prediction app: flat list with trash buttons (unwieldy at scale).

A

Collapsible list grouped by class

Each feature type is a collapsible header showing count. Expand to see individual objects with delete button. Hover an object to highlight it on canvas.

Pros

  • Compact by default (collapsed)
  • Expand only the class you care about
  • Hover-to-highlight finds the object on canvas
  • Per-object delete without switching to eraser tool

Cons

  • 42 items expanded is still a long list
  • Needs hover-highlight implementation
B

Click-to-select on canvas + delete key

No object list panel. Click an annotation on the canvas to select it (highlighted outline). Press Delete/Backspace to remove. Classes panel shows counts only.

Pros

  • Cleanest UI — no list at all
  • Spatial selection (click where you see the problem)
  • Panel stays compact always

Cons

  • Hard to select overlapping objects
  • No overview of all objects
  • More complex canvas interaction (click to select vs click to draw)
C

Collapsible list + click-to-select (combined)

Collapsible class groups in the panel. Click an object in the list OR on the canvas to select it. Selected object is highlighted in both places. Delete via button or keyboard.

  • Two ways to find and select objects
  • Bidirectional: list highlights canvas, canvas highlights list
  • Most complete interaction model

Cons

  • Most complex to implement
  • Scope creep risk — can defer canvas-click-to-select to later
